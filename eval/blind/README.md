# Blind evaluation protocol

**Status: NOT RUN. There is no measured agreement score.** Do not report one.

## Why this exists

`dev.jsonl` and `holdout.jsonl` were written by the author of the rules, with
one golden branch per gate. A perfect score against them proves only that the
engine follows its own rules. An independent annotator is the only way to
falsify the claim that those rules match a reasonable release judgement.

## What the annotator sees

`prompts.jsonl`, generated by `scripts/gen_blind_prompts.py`. Each row contains
only `id`, `suite` and `contract`. The fields `expected`, `why` and `kind` are
**deliberately removed** — `kind` would leak which gate is being exercised.
Do not hand-edit `prompts.jsonl`; regenerate it from the suites.

The annotator must NOT see:

- the engine's output for these cases,
- the scored sets or their golden labels,
- this repository's README claims about accuracy.

## The question to answer

For each segment in each contract, answer one question:

> Given this offline evidence and this contract, would you let the model act
> alone on this traffic? Answer `AUTO` (yes), `FENCE` (no, route to a human or
> disable), or `HOLD` (the evidence is not enough to decide).

Record why in your own words. Disagreements are the valuable output: a case
where a careful reader says `FENCE` and the engine says `AUTO` is a candidate
defect, not an annotation error to be smoothed away.

## Annotation file format

Put independent annotations at `eval/blind/annotations.jsonl`, one JSON object
per line:

```
{"id":"dev-001","verdicts":{"thin":"HOLD"}}
{"id":"ho-007","verdicts":{"five_hundred":"FENCE","one_thousand":"AUTO"}}
```

This file is gitignored on purpose: it is a measurement input, not a source
file, and it must not be silently committed as if it were a result.

## Scoring

```
python scripts/blind_eval.py
python scripts/blind_eval.py eval/blind/annotations.jsonl
python scripts/blind_eval.py eval/blind/annotations.jsonl --json
```

The script compares the annotator **against the engine's verdicts**, not
against the author-written golden labels. It reports agreement, a Wilson 95%
interval when the sample permits, and a full disagreement list. With no
annotation file it prints `NOT RUN` and invents no number.

Agreement here is not a model accuracy figure. It is a measure of how often an
independent reader agrees with deterministic gates, and its interval will be
wide until enough cases are annotated.
